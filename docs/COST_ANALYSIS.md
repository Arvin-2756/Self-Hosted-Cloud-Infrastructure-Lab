# Cost Analysis

The lab is designed around existing hardware, so the main costs are electricity, storage, replacement drives, and optional hosted services.

A simple monthly estimate is:

```text
monthly_cost = (watts / 1000) * hours_per_day * days_per_month * price_per_kWh
```

Track idle and peak draw separately. Include the cost of backup storage and domains when comparing this platform with managed cloud services.
